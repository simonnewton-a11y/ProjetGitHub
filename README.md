\# Ma calculatrice Python



\## Présentation du projet



Ce projet consiste à créer une calculatrice simple en langage Python dans le cadre d'un travail pratique sur l'utilisation de Git et GitHub.



\## Objectifs



\- Apprendre à créer et organiser un projet informatique.

\- Découvrir les commandes principales de Git.

\- Utiliser GitHub pour sauvegarder et partager son code.

\- Apprendre à suivre les différentes étapes de développement grâce aux commits.



\## Fonctionnalités



La calculatrice permet de réaliser cinq opérations :

\- Addition

\- Soustraction

\- Multiplication

\- Division

\- Puissance



Elle possède également :

\- Un historique des calculs effectués.

\- Une gestion des erreurs de saisie.

\- Une vérification pour empêcher la division par zéro.

\- La possibilité d'effectuer plusieurs calculs à la suite.



\## Technologies utilisées



\- Python 3.12

\- Git

\- GitHub

\- PowerShell



\## Lancement du programme



1\. Installer Python.

2\. Télécharger ou cloner le dépôt GitHub.

3\. Ouvrir un terminal dans le dossier du projet.

4\. Exécuter la commande suivante :



```bash

python calculatriceTP.py

```
